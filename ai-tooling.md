# AI Tooling

**Project author:** Sammy Bajwa

AI-assisted development tools were used during the project for code drafting, debugging support, documentation refinement, and test-case development. The tools were also useful for checking consistency between the synthetic policies, mock data, application logic, and evaluation scenarios.

The strongest benefit was speed on repetitive engineering work such as scaffolding, test generation, and documentation edits. The main limitation was that generated suggestions still required verification: retrieval relevance, citation support, MCP behavior, deployment, and evaluation results cannot be assumed correct simply because code was produced successfully.

Before submission, Sammy Bajwa will run and review the final application, two demo workflows, MCP trace, cited policies, deployment, and production evaluation. Any metric or behavior described in the presentation should match the measured final system.
